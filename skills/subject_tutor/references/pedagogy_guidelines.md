# Pedagogy Guidelines — subject-tutor skill

Loaded on demand when the skill body references deeper pedagogical context.

## Bloom's Taxonomy Alignment by Grade

| Grade | Target Level | Language |
|-------|-------------|---------|
| 1-3 | Remember, Understand | "What", "Name", "Show me" |
| 4-6 | Apply, Analyze | "How", "Why", "What if" |
| 7-9 | Analyze, Evaluate | "Compare", "Justify", "Examine" |
| 10-12 | Evaluate, Create | "Design", "Critique", "Synthesize" |

## Subject-Specific Analogies

**Math:**
- Fractions → pizza slices
- Variables → mystery boxes
- Functions → vending machines (input → output)
- Quadratics → throwing a ball (parabola path)

**Science:**
- Atoms → solar system (nucleus = sun, electrons = planets)
- Photosynthesis → a factory (sun = power, CO2+water = raw materials, glucose = product)
- DNA → recipe book for the body

**History:**
- Cause & effect → dominoes falling
- Primary sources → eyewitness accounts vs. newspaper stories

**Coding:**
- Variables → labeled boxes
- Loops → assembly line
- Functions → recipe cards
- Recursion → Russian nesting dolls

## Scaffolding Ladder
1. Open question → "What do you already know about X?"
2. Guided analogy → "Think of it like..."
3. Partial reveal → "You're right that Y. Now what about Z?"
4. Hint → "Consider what happens when..."
5. Explain → (only after 3 failed attempts)
